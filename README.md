# Job Application Tracker

A Spring Boot REST API project that helps users organize and manage their job applications in one place. Users can create, view, update, and delete application records, including company name, job title, application date, job link, status, and description.

## Features
- Create a new job application
- View all applications or retrieve one by ID
- Update application details and status
- Delete an application

## Tech Stack
- Java 21
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- Postman

## API Base URL
`http://localhost:8080/api/applications`
